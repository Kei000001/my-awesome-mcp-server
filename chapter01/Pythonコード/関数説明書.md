# 関数説明書

- 対象ファイル: utils.py
- 概要: ユーティリティ関数集
- 関数数: 2

## calculate_area(width, height)

| 項目 | 内容 |
|---|---|
| 説明（docstring） | 長方形の面積を計算する |
| 引数 | `width`: 幅、`height`: 高さ |
| 戻り値 | `width * height` の計算結果 |
| コメント | 幅と高さを掛け算 |

使用例:

```python
calculate_area(10, 20)  # => 200
```

## format_price(price)

| 項目 | 内容 |
|---|---|
| 説明（docstring） | 価格を通貨形式にフォーマット |
| 引数 | `price`: 価格（数値） |
| 戻り値 | 円記号付き・3桁カンマ区切りの文字列 |
| コメント | 3桁ごとにカンマを入れて円記号を付ける |

使用例:

```python
format_price(98000)  # => "¥98,000"
```

| 項目 | 内容 |
|---|---|
